# Print method for STID objects

Provides a detailed printout of STID object contents, including
STID_info, meta_data_record, SingleSampNiche, and MultiSampNiche
information.

## Usage

``` r
# S3 method for class 'STID'
print(x, ...)
```

## Arguments

- x:

  An STID object

- ...:

  Additional arguments passed to print

## Value

Invisibly returns the object
